# PRISM

### Pull Request Risk & Impact Scoring Manager

PRISM is a developer intelligence platform that analyzes GitHub Pull Requests and generates a risk assessment based on code changes, dependency impact, security findings, logic changes, and testing recommendations.

## 🚀 Features

- GitHub OAuth authentication
- GitHub repository discovery
- Pull Request analysis
- Code diff analysis
- Function-change detection
- Dependency impact analysis
- Dependency depth calculation
- Security vulnerability checks
- Risk score calculation
- Risk level classification
- Risk explanation
- Automated test recommendations
- Analysis history
- Dependency impact graph
- PostgreSQL persistence
- Modern Next.js dashboard
